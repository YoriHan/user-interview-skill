# 用户访谈纲要整理 · Claude Code Skill

从腾讯会议转写链接自动整理用户访谈记录，以"找场景"为核心目标，提炼结构化提纲并上传到 GitHub。

## 功能

- 用 headless browser 抓取腾讯会议转写页面（多次滚动获取完整逐字稿）
- 以**逐字稿原话**为依据整理，AI 纪要仅作骨架参考
- 自动读取 GitHub 已有文件，确定下一个编号（01、02、03…）
- 支持新建和更新已有文件
- 上传到 `sheet0/gtm` 的 `Launch/user interview/` 目录

## 使用方式

1. 将 `SKILL.md` 放入 `~/.claude/skills/user-interview/SKILL.md`
2. 在 Claude Code 中触发：

```
/user-interview
```

然后提供腾讯会议转写链接和受访者标识即可。也可以直接粘贴逐字稿文本。

## 输出格式

每份访谈生成一个编号 Markdown 文件，例如 `03-Helio用户访谈-用户-01.md`，包含：

- **用户背景**：身份、团队、工作场景、AI 工具使用习惯
- **AI 工具全景**：所有在用工具、场景、付费情况、用户评价
- **核心使用场景**（P0）：每个场景独立小节，写清配置方式、触发时机、产出、竞品对比、原话引用
- **Aha Moment 与卡点**：最爽/最不爽的具体瞬间，未使用功能的真实原因
- **产品定位认知**：用户如何理解 Helio 与其他工具的关系
- **问题反馈与需求**：Bug / 认知卡点 / 功能需求
- **付费意愿**：具体价格区间、货币单位、付费前提

## 整理原则

- 逐字稿原话 > AI 纪要，关键结论必须有原话支撑（`> 「」` 格式）
- 未使用功能写真实原因，不写"未探索"
- 竞品必须点名，评价要具体
- 删除与该用户无关的模块，不留空行占位
